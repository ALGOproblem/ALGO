1️⃣ BOJ 2533 - 사회망 서비스 
문제 요약: 트리 구조에서 모든 노드가 아이디어를 수용하도록, 최소한의 얼리 어답터 수를 구하라.

DFS+DP문제
처음에는 BFS쓰다가 DFS로 바꿈

DP는 결국 상태를 저장하고 점화식을 세우는 것

이중배열로 상태를 저장하고 꺼내서 답을 도출하면됨.
인싸인 경우와 아닌 경우 두가지를 생각해서 점화식을 세우면 풀 수 있는 문제제

2️⃣ BOJ 17070 - 파이프 옮기기 2 
문제 요약: (1,1)-(1,2) 위치에서 시작해 파이프를 밀며 (N,N)까지 이동하는 모든 경우의 수 계산.

똑같이 dp로 상태를 저장하고 푸는 문제
근데 조건이 상당히 많다. 

가로로 갈때, 세로로 갈때, 대각선으로 갈때 조건들을 잘 안넣으면 틀린다.
나머지는 그냥 for문으로 dp 하는 것 뿐임.

3️⃣ BOJ 14503 - 로봇 청소기 
문제 요약: 로봇이 청소 가능한 칸을 조건에 따라 순회하며 청소한 칸의 수를 구하라.

현재 위치가 청소되지 않는 곳인 0이면 청소후 2로 표시--청소 횟수 증가
함수 check 호출후에 현재 방향 기준으로 청소할 수 있는 인접 칸 확인
있다면 해당 방향을 반환

청소 가능 칸 있으면 해당 방향으로 전진
아니면 반대 방향으로 후진 --만약에 벽인 1이면 while문 종료



4️⃣ BOJ 17144 - 미세먼지 안녕! (공기청정기 시뮬레이션)
문제 요약: T초 동안 미세먼지 확산 + 공기청정기 작동을 시뮬레이션

diffusion(): 미세먼지 확산 (상하좌우로 퍼지며 기존 칸은 감소)
upmove(): 공기청정기 상단(위쪽) 순환
downmove(): 공기청정기 하단(아래쪽) 순환

그다음순환
공기청정기가 위차흔 곳은 따로 큐에 저장 각 칸의 먼지를 기준으로 확산될 양도 계산하여 저장하는 것임
