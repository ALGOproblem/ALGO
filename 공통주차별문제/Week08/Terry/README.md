## 14053. 로봇 청소기 (골드5)

### 풀이 과정
- 구현 문제라서 작성할 함수 목록, 동작 목록을 먼저 시각적으로 나타냈습니다.
- 순수 함수 작성 연습했습니다
    - matrix를 전역변수로 사용했는데 이건 귀찮아서 매개변수로 작성하지 않았습니다 ㅎㅅㅎ
    - matrix때문에 순수함수는 아니지만 일단 했습니다

> 작성할 함수 목록
> 
1. 현재칸 더러워? (`isDirty`) (좌표)
2. 주변칸 더러워? (`isDirtyAround`) (좌표)
3. 앞에 더러워? (`isDirtyFront`) (좌표, direction)
4. 치워 (`cleanFloor`) (좌표)
5. 후진 가능? (`canReverse`) (좌표, direction)
6. 반시계 회전 (`rotate`) (direction)
7. 방향에 따른 좌표 리턴 함수 (좌표, direction) 
8. 범위를 안쪽인가? (`isMatrix`)

> 로봇 동작 순서
> 
1. 현재칸 청소 안되어 있나? -> 청소
2. 현재 주변 4칸 중 청소되지 않은 빈칸이 없어?
    1. 바라보는 방향을 유지하고 한 칸 후진할 수 있으면 한 칸 후진하고 1번
    2. 뒤가 벽이라 후진 할 수 없으면 정지
3. 현재 주변 4칸 중 더러운 칸이 있으면
    1. 반시계 방향으로 90도 회전
    2. 바라보는 방향을 기준으로 앞쪽 칸이 청소되지 않은 빈칸인 경우 한 칸 전진
    - 회전하고 앞이 벽이거나 범위 밖이어도 다음 동작하는 듯
4. 1번으로 돌아간다.

## 17069. 파이프 옮기기2 (골드4)

### 풀이 과정
- 각 요소에서 위치
  - 0, 1, 2 => 가로, 세로, 대각선

- 각 노드별
